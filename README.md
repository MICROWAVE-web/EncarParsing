# EncarParsing

Парсер автомобилей с сайта Encar (корейский автомобильный маркетплейс). Проект собирает данные об автомобилях через API Encar и сохраняет их в базу данных SQLite.

## Описание

Проект состоит из двух основных компонентов:

1. **browser_data_updater.py** - обновляет cookies и headers браузера через Selenium для доступа к API Encar
2. **run_scraper.py** - основной скрипт парсинга, который использует полученные cookies/headers для запросов к API и сохранения данных в БД

## Требования

- Python 3.8+
- Chrome/Chromium браузер (для Selenium)
- ChromeDriver (устанавливается автоматически через webdriver-manager)

## Установка

1. Клонируйте репозиторий или скачайте проект

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Для Linux серверов без GUI дополнительно установите:
```bash
sudo apt-get install xvfb
```

## Конфигурация

Проект использует переменные окружения для настройки. Создайте файл `.env` в корне проекта или установите переменные окружения:

```env
# Файл с cookies и headers
COOKIES_FILE=encar_cookies.json

# Файл логов
LOG_FILE=encar_truck_scraper.log

# База данных SQLite
DB_FILE=encar_cars.db

# URL API Encar
BASE_API_URL=https://api.encar.com/search/car/list/premium

# Параметры парсинга
START_YEAR=2025          # Начальный год для парсинга
MIN_YEAR=2008            # Минимальный год для парсинга
PAGE_SIZE=1000           # Размер страницы
OFFSET_STEP=1000         # Шаг смещения
INITIAL_OFFSET=0         # Начальное смещение
REQUEST_TIMEOUT=15       # Таймаут запроса (секунды)
REQUEST_PAUSE_SECONDS=1.6  # Пауза между запросами (секунды)
DOUBLE_PAGES_TO_SKIP=10  # Количество повторяющихся страниц для остановки
CYCLE_PAUSE=60           # Пауза между циклами парсинга (секунды)

# Настройки микросервиса уведомлений (опционально)
NOTIFICATION_SERVICE_NAME=EncarParsing
NOTIFICATION_API_BASE=http://188.225.73.94/api/notifications
NOTIFICATION_TIMEOUT=5
```

Все параметры имеют значения по умолчанию, поэтому `.env` файл не обязателен.

## Использование

### Первый запуск

При первом запуске необходимо получить cookies и headers:

```bash
python browser_data_updater.py
```

Этот скрипт:
- Откроет браузер Chrome через Selenium
- Перейдет на сайт Encar
- Соберет cookies и headers
- Сохранит их в файл `encar_cookies.json`
- Проверит валидность данных тестовым запросом к API

### Запуск парсера

После получения cookies и headers запустите основной скрипт парсинга:

```bash
python run_scraper.py
```

Скрипт будет:
- Проверять валидность cookies/headers при запуске
- Автоматически обновлять их при необходимости
- Парсить автомобили по годам (от START_YEAR до MIN_YEAR)
- Сохранять данные в SQLite базу данных
- Работать в бесконечном цикле с паузами между циклами

## База данных

Данные сохраняются в SQLite базу данных с таблицей `cars`:

| Поле | Тип | Описание |
|------|-----|----------|
| id | TEXT | Уникальный ID автомобиля |
| condition | TEXT | Состояние (JSON) |
| brand_fk | TEXT | Производитель |
| model_fk | TEXT | Модель |
| badgeDetailNm | TEXT | Модификация |
| transmission | TEXT | Коробка передач |
| fuelNm | TEXT | Тип топлива |
| year | REAL | Год выпуска |
| formYear | TEXT | Формальный год |
| mileage | REAL | Пробег |
| price | REAL | Цена |
| sell_type | TEXT | Тип продажи |
| mdfDt | TEXT | Дата изменения на сайте |
| collected_at | TEXT | Дата сбора данных |

## Особенности

- **Автоматическое обновление cookies**: При обнаружении устаревших cookies скрипт автоматически обновляет их
- **Валидация данных**: Проверка cookies/headers перед началом парсинга
- **Обработка ошибок**: Автоматическое обновление cookies при получении 401/403 ошибок
- **Логирование**: Подробные логи в файл и консоль
- **Уведомления об ошибках**: Интеграция с микросервисом уведомлений (опционально)
- **Защита от дубликатов**: Отслеживание уже обработанных автомобилей в цикле
- **Оптимизация запросов**: Паузы между запросами для избежания блокировок

## Логирование

Логи сохраняются в файл, указанный в `LOG_FILE` (по умолчанию `encar_truck_scraper.log`). Уровни логирования:
- **DEBUG**: Детальная информация для отладки
- **INFO**: Общая информация о процессе парсинга
- **WARNING**: Предупреждения (например, устаревшие cookies)
- **ERROR**: Ошибки (также отправляются на микросервис уведомлений, если настроен)

## Примечания

- На Linux серверах без GUI автоматически используется виртуальный дисплей (Xvfb)
- Скрипт работает в бесконечном цикле, для остановки используйте Ctrl+C
- При первом запуске может потребоваться время на установку ChromeDriver
- Рекомендуется запускать скрипт в screen/tmux для долгосрочной работы на сервере
